# 포트폴리오 반응형 설계

> 대상: `/Users/heebiny/취업/portfolio/index.html` (GitHub Pages 정적 페이지 1개)
> 작성: 2026-11-16 · 이 문서가 기준이다. CSS를 바꿀 때는 이 문서를 먼저 고치고 구현한다.

## 1. 원칙

| # | 원칙 | 구현 방식 |
|---|---|---|
| P1 | **글자 크기는 구간별 고정** — 창을 조금 줄이고 늘려도 글자는 그대로, 구간이 바뀔 때만 한 단계 바뀐다 | 루트 `font-size`를 브레이크포인트마다 px로 지정, 모든 글자는 `rem` |
| P2 | **레이아웃·요소 크기는 창 폭에 실시간 반응** — 창을 끄는 동안 폭·여백·간격·아이콘이 바로 따라온다 | 폭은 `fr`·`%`, 여백·간격·아이콘은 `clamp(최소, vw, 최대)` |
| P3 | **열 수는 구간별 고정** — 카드가 한 줄에 몇 개 놓이는지는 구간이 정한다 | `grid-template-columns: repeat(N, minmax(0,1fr))` |
| P4 | **JS 없이 CSS만으로 반응** — 리사이즈 이벤트 처리 없음, 지연 없음 | 미디어쿼리 + `clamp()` |
| P5 | **밝은 테마 고정** — OS 다크 모드와 무관 | `color-scheme: light`, 다크 미디어쿼리 없음 |

전체 확대·축소(루트 글자 크기를 `vw`에 연동) 방식은 쓰지 않는다. 넓은 화면에서 글자가 과하게 커져 UX가 어색했다(2026-11-15 시도 후 폐기).

## 3. 타이포그래피 (rem → 구간별 실제 px)

| 요소 | XS | M | L | XL |
|---|---|---|---|---|
| 이름 (h1) | 3rem → 45px | 3.75rem → 56px | 4.5rem → 72px | 5rem → 85px |
| 소개 문장 | 1.0625rem → 16px | 〃 → 16px | 〃 → 17px | 〃 → 18px |
| 섹션 제목 (h2) | 2rem → 30px | 〃 → 30px | 〃 → 32px | 〃 → 34px |
| 카드 제목 | 1.1875rem → 17.8px | 〃 | 〃 → 19px | 〃 → 20.2px |
| 카드 본문 | 0.9375rem → 14px | 〃 | 〃 → 15px | 〃 → 16px |
| 보조 글자 (태그·근거) | 0.75~0.875rem → 11~13px | 〃 | 12~14px | 12.8~14.9px |
| 기술 칩 (mono) | 0.6875rem → 10.3px | 〃 | 11px | 11.7px |

글꼴: 이름·제목·본문 전체 **Gmarket Sans**(Light 300 / Medium 500 / Bold 700, 눈누 jsDelivr CDN woff), 기술 칩·섹션 라벨 **IBM Plex Mono**.
위계는 글꼴을 섞지 않고 크기·굵기 차이로만 준다(본문 Medium, 제목 Bold).

**글자 세로 비율**: Gmarket Sans는 가로로 넓어 보여 페이지 컨테이너(`.wrap`) 전체를 `scaleX(0.9)`로 압축하고 폭을 `100% / 0.9`로 넓혀 상쇄한다. 레이아웃 폭은 그대로, 모든 글자가 약 1.11배 세로로 길어 보인다. 원형 요소(hero 원, 카드 점)는 `scaleX(1/0.9)`·폭 보정으로 원형 유지.
**줄 간격**: 본문 1.8, 소개 문장 1.95, 이름 1.2, 카드 제목 1.5.

## 4. 레이아웃과 요소 크기 (창 폭에 실시간 반응)

| 항목 | 값 | 설명 |
|---|---|---|
| 페이지 폭 | 창 폭 100% (최대 폭 제한 없음) | 양옆 빈 공간 없이 창을 채움 |
| 좌우 여백 | `clamp(16px, 3vw, 72px)` | 375px→16 · 1280px→38 · 1920px→58 |
| 위 여백 | `clamp(12px, 1.8vw, 32px)` | |
| 카드 간격 | `clamp(12px, 1.3vw, 26px)` | 카드 그리드·작업 그리드 공통 |
| 첫 화면(hero) 높이 | L·XL: `100svh − 위아래 여백` / XS·M: 내용 높이 | 큰 화면은 첫 화면이 창 높이를 채움. 작은 화면은 위아래 빈 공간 없이 내용만큼(XS·M에서는 "프로젝트 보기 ↓" 숨김) |
| hero 안쪽 여백 | `clamp(28px,4vw,80px)` × `clamp(22px,4.5vw,96px)` | |
| hero 아이콘 원 | `clamp(140px, 22vw, 440px)` | XS에서는 숨김 |
| 섹션 판 안쪽 여백 | `clamp(16px, 2vw, 40px)` | 업무·개인 영역 |
| 카드 안쪽 여백 | `clamp(16px, 1.4vw, 28px)` | 카드·작업·문의·기술스택 공통 |

## 5. 열 수 (구간별 고정)

| 영역 | XS | M | L | XL |
|---|---|---|---|---|
| hero | 1열 (아이콘 숨김) | 2열 (1.4fr : 0.6fr) | 〃 | 〃 |
| 업무 프로젝트 (4장) | 1 | 2 | 2 (2×2) | 4 (한 줄) |
| 개인 프로젝트 (6장) | 1 | 2 (3줄) | 3 (2줄) | 3 (2줄) |
| 맡을 수 있는 작업 (4장) | 1 | 2 | 4 | 4 |

업무 카드는 4장이라 3열을 쓰지 않는다(한 장이 혼자 남음). 개인 카드는 6장이라 2·3열만 쓴다.

## 6. 색·장식

- 배경: 웜 화이트 `#FAF8F4` 고정. 글자·주요 면: 블랙 `#1A1A19` / 차콜 `#1F1F1E`(hero). 포인트: 절제된 블루 `#2F5BD3`(링크·핵심 배지 외곽선·점·작업 카드 상단선)만.

- 업무/개인 섹션: 같은 배경 `#F3F0EA` + 같은 경계선. 구분은 WORK/PERSONAL 라벨과 제목으로.

- 강조는 전공·기술 용어에만: 빨강 2곳, 굵게 1곳. 밑줄 없음.
